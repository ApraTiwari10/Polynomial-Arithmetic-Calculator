# 🧮 Polynomial Arithmetic Calculator

A C++-based Polynomial Arithmetic Calculator designed to perform polynomial operations using **Object-Oriented Programming (OOP)** and **Singly Linked Lists**.

## ✨ Features

* ➕ Polynomial Addition
* ➖ Polynomial Subtraction
* ✖️ Polynomial Multiplication
* 📊 Polynomial Evaluation
* 🔗 Singly Linked List implementation
* 🧩 Object-Oriented Programming approach
* 💻 Interactive and user-friendly interface

## 🛠️ Technologies Used

* **C++**
* **OOP**
* **Singly Linked List**
* **HTML, CSS & JavaScript** *(for the interface, if included)*

## 🎯 Concepts Demonstrated

This project demonstrates the practical application of **Data Structures, Dynamic Memory Management, Object-Oriented Programming, and Polynomial Mathematics**.

## 🚀 How to Run

1. Clone or download the repository.
2. Open the C++ source files in a C++ IDE or VS Code.
3. Compile the program using a C++ compiler.
4. Run the generated executable.

## 👩‍💻 Project

Built as a practical implementation of **DSA and OOP concepts** through polynomial arithmetic.
